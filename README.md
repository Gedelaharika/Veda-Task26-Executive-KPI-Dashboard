# Veda Technology – Task 26

## Executive KPI Dashboard – Superstore Sales

### Project Overview

This project is an executive KPI dashboard created using **Microsoft Power BI**. The dashboard provides a one-page management view of Superstore sales performance with interactive filters and key business metrics.

### Objective

To design a concise and interactive business dashboard that helps users understand sales, profit, transactions, and product performance.

### Tools Used

* Microsoft Power BI
* DAX
* Superstore Dataset

### Key KPIs

| KPI                | Definition                                          |
| ------------------ | --------------------------------------------------- |
| Total Sales        | Sum of all sales amounts in the dataset.            |
| Total Profit       | Sum of profit generated from all transactions.      |
| Total Transactions | Total number of transaction records in the dataset. |
| Profit Margin      | Profit expressed as a percentage of total sales.    |

### Dashboard Features

* Interactive **Category** slicer
* Interactive **Segment** slicer
* Interactive **Region** slicer
* Total Sales KPI
* Total Profit KPI
* Total Transactions KPI
* Profit Margin KPI
* Sales by Category visualization
* Sales by Region visualization
* Top 5 Sub-Categories by Sales visualization

### Dashboard Design

The dashboard is designed as a single-page executive report with limited KPIs and focused visualizations to reduce clutter and make important business information easy to understand.
